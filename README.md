# Gost-standart

Шаблоны отчёта с титульным листом ИТМО и оформлением на основе ГОСТ 7.32–2017.

- `main.tex` — LaTeX: титульный лист, разделы, таблица, рисунок и формула.
- `main.typ` — аналогичный шаблон для Typst 0.13+.
- `ТИТУЛ для оформления ЛР.docx` — титульный лист Word с памяткой и примерами.

Заполните дисциплину, тему, номер работы, группу и ФИО, затем замените примеры
своими материалами. В Word перед сдачей удалите памятку.

## Сборка

LaTeX — TeX Live / MiKTeX или Overleaf; выполните два прохода:

```sh
xelatex main.tex
xelatex main.tex
```

Для Times New Roman положите рядом `times.ttf`, `timesbd.ttf`, `timesi.ttf`
и `timesbi.ttf`. Без них используется Tempora. Также поддерживается pdfLaTeX
со шрифтом Tempora.

Typst — установите Times New Roman и выполните:

```sh
typst compile main.typ main.pdf
```

Оба шаблона создают `main.pdf`: собирайте их по отдельности.

По умолчанию: А4, кегль 14 пт, полуторный интервал, поля 30/15/20/20 мм
(слева/справа/сверху/снизу), абзац 1,25 см. Дополнительные настройки находятся
в начале исходников. При сдаче учитывайте требования преподавателя.
