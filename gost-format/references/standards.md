# Применимость и нормативная основа

## Источники

Снимок сведений: 09.11.2026. [Официальная карточка ГОСТ 7.32–2017](https://protect.gost.ru/gost/details/7d280e43-7036-4a69-8e6e-d15867028343) указывает действующий статус и поправки ИУС 2–2019, 3–2020, 1–2022. Карточка подтверждает статус, но сама по себе не подтверждает содержание каждого пункта. Перед утверждением актуального соответствия проверь карточку и тексты применимых поправок. Если содержание поправок недоступно, не отмечай его проверенным.

Текст для чтения пунктов: [официальное издание, копия на сайте ДонНУ](https://science.donnu.ru/wp-content/uploads/2023/10/gost_7.32-2017.pdf). Это копия издания 2017 года, а не гарантия включения всех поздних поправок. Сверяй номера и смысл требований с текстом, а не с поисковыми выдержками.

## Куда относится документ

ГОСТ 7.32–2017 предназначен прежде всего для отчётов о НИР. Учебная лабораторная из репозитория использует его правила оформления вместе с локальным титульным листом. Для полноценного отчёта о НИР проверь состав обязательных элементов по разделам 4–5 и реквизиты титула по 5.1, 6.10: короткий лабораторный шаблон их не заменяет.

Для ВКР и курсовой необходима методичка конкретного вуза; применение 7.32 не следует из одного названия работы. Для диссертаций, организационно-распорядительных и конструкторских документов найди профильный действующий стандарт отдельно. Не дополняй этот скилл неподтверждённым «единым ГОСТом на все работы».

## Контрольные параметры ГОСТ 7.32–2017

Это краткая карта для применения, не полный текст стандарта. Исключения проверяй в соответствующем пункте.

| Объект | Требование | Пункт |
| --- | --- | --- |
| Страница | А4; слева 30, справа 15, сверху и снизу 20 мм | 6.1.1 |
| Основной текст | Чёрный, от 12 пт, интервал 1,5; Times New Roman рекомендован; абзац 12,5 мм | 6.1.1 |
| Структурный заголовок | По центру, прописными, без конечной точки; новый лист | 6.2.1 |
| Раздел/подраздел | С абзаца, полужирный; без точки после номера и в конце; раздел с нового листа | 6.2–6.4 |
| Страницы | Сквозные арабские номера снизу по центру; титул учитывается, номер скрыт | 6.3 |
| Рисунок | Ссылка в тексте; подпись снизу по центру: «Рисунок 1 — Название» | 6.5 |
| Таблица | Ссылка в тексте; подпись сверху слева без абзаца: «Таблица 1 — Название» | 6.6 |
| Формула | Отдельная строка, центр; номер справа в скобках; пояснения символов — отдельными строками | 6.8 |
| Источники | Отсылки в квадратных скобках; список по первому упоминанию, номера с точкой | 6.9, 6.16 |
| Приложение | Новый лист; обозначение и заголовок; ссылка в тексте; общая нумерация страниц | 6.17 |

Не превращай разрешённый вариант в нарушение. Для отдельных объектов допустимы оговорённые стандартом отступления: А3, меньший шрифт в таблице, нумерация объектов по разделам. Их применимость подтверждай пунктом и содержанием документа.

Выравнивание основного текста по ширине, 14 пт, нулевые интервалы до/после обычного абзаца и запрет висячих строк — рабочие настройки профиля репозитория. Не приписывай их все пункту 6.1.1.

## Библиография

Различай описание источника и библиографическую ссылку. ГОСТ Р 7.0.100–2018 относится к библиографическому описанию, ГОСТ Р 7.0.5–2008 — к ссылкам; применимость и актуальность каждого проверяй отдельно по официальной карточке и методичке. У 7.32 есть собственные нормативные ссылки: не заменяй их автоматически только потому, что известен более новый стандарт.

Проверяй автора, заглавие, издание, год, страницы, URL и DOI по самому источнику. Отсутствующее обозначай как недостающие сведения, не создавай правдоподобные реквизиты. Дата обращения — дата реального обращения к ресурсу, а не дата из демонстрационного шаблона. Согласуй все номера отсылок со списком после перестановок.
